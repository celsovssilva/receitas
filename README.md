🍳 Receitas 
O Receitas é uma plataforma web desenvolvida com Django para compartilhamento e organização de receitas culinárias. O projeto foca em oferecer uma experiência intuitiva para o usuário buscar pratos, visualizar ingredientes e seguir o passo a passo do modo de preparo, além de contar com uma área administrativa para gestão do catálogo.

🛠️ Tecnologias e Recursos
Python: Linguagem de programação principal.

Django Framework: Estrutura para desenvolvimento rápido e seguro.

Django Templates: Motor de renderização dinâmica para o front-end.

Pillow: Biblioteca para processamento e upload de imagens das receitas.

Django Admin: Interface completa para curadoria das receitas e categorias.

🎯 Funcionalidades Principais
Busca Inteligente: Filtre receitas por nome ou ingredientes.

Categorização: Organização por tipos (ex: Massas, Sobremesas, Carnes).

Galeria de Imagens: Upload e exibição de fotos dos pratos prontos.

Detalhes da Receita: Listagem clara de tempo de preparo, rendimento, ingredientes e instruções.

Área do Administrador: Controle total de usuários e conteúdos publicados.
